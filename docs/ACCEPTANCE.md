# Программа и методика испытаний

DDS-2026 / 0.1.0. Объект: программа-минимум Даниила. Статус: рабочая командная редакция, не акт государственной приёмки.

## Условия

Локальные API/UI/PostgreSQL15, миграция 0001, seed-классификатор/сценарии. Синтетические учётные записи. ML_MODE=mock, затем отдельная проверка ML_MODE=local с недоступным сервисом. Браузер Chromium, настольный и мобильный размеры.

## Испытания

| № | Действия | Ожидаемый результат |
|---|---|---|
| 1 | Вход, неверный пароль, запрос без JWT | Успешный вход; 401 для неверных данных |
| 2 | Запрос чужой карточки обучающимся | 404 без выдачи данных |
| 3 | Открытие сценария/карточки | Сессия, incoming, received и серверное время |
| 4 | Принята → реагирование → завершение | История и конечная блокировка |
| 5 | Отказ без комментария | 422; с комментарием сохраняется |
| 6 | Повторная отправка устаревшей версии | 409; нет потери актуальных данных |
| 7 | Превышение 30с | Замечание по времени подтверждения |
| 8 | Завершение и повторное завершение | Один сохранённый результат |
| 9 | Проверка преподавателя | Отдельное заключение; исходная оценка сохранена |
| 10 | Недоступный/ошибочный ML | Fallback; API/карточки доступны |
| 11 | Сетевой сбой при сохранении | Ошибка и сохранённое содержимое открытой формы |
| 12 | Перезапуск API/БД | Ранее сохранённые результаты доступны |
| 13 | Экран 1440px и 390px | Управление доступно, нет общего горизонтального переполнения |
| 14 | Compose api/ui/db | Миграция, seed, health, UI и сохранение данных |
| 15 | Генерация и импорт сценария преподавателем | Предпросмотр вариантов; импорт выбранных с авторством; повторный импорт →409; без ML/в mock →503 с подсказкой |

## Регистрация

Команды, версии, время и фактические результаты в VERIFICATION.md. Отдельно регистрируются невыполненные проверки. 100 пользователей, 100 записей/с и реальная VoIP-задержка относятся к общей системе и не подтверждаются этим функциональным протоколом.
