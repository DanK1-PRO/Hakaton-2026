# Plugins and Skills

Project skills physically exist in .agents/skills:
hackathon-orchestrator, source-router, vertical-slice-builder, ml-boundary, integration-gate.

Use only relevant skill bodies. The built-in skill-creator was read when creating these files. PDF/spreadsheet tooling is used for source inspection, not runtime.

GitHub access currently works through Git credential manager and CLI HTTPS. No GitHub plugin installation is required for clone/push. Browser checks use local Playwright. The installed Figma/Drive tools are unnecessary for the present local source package.

Do not install unrelated collaboration/cloud plugins. Security review tooling may be added for a requested future audit, not as a gate invented for this MVP. A plugin does not improve domain fidelity without the customer source packet.

Subagent availability is environment-dependent. This implementation used the available execution tools; do not claim parallel agents were launched when no such tool exists.
