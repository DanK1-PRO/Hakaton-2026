# UI Components

Ant Design ConfigProvider ru_RU and shared theme; existing @ant-design/icons.
- Header/role/clock/navigation; status footer.
- Paginated Table, expandable incident description, text/type/status filters.
- Source-backed class labels; address/description blocks.
- Phone controls and visible call duration.
- Server-provided transition Select with comment Form.
- Timeline from recorded events.
- Evaluation findings/timing and instructor feedback.
- Result CSV command and admin account form.

Redux Toolkit Query owns query caching/invalidation; dialogs hold unsaved form state. Semantic headings, input labels, tooltips and icon-button aria-labels are provided. Use screenshot checks for desktop/mobile after layout changes.
