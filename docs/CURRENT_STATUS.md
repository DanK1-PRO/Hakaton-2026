# Текущее состояние

Обновлено: 29.09.2026. Рабочая сборка UI/API/PostgreSQL и локального ML.

## Что работает

- Русский АРМ диспетчера: поиск и фильтры происшествий, карточка, классификация,
  панель реагирования, история действий, статусы с комментариями.
- Учебный цикл: 3 синтетических занятия, подтверждение за 30 секунд, этапы реагирования,
  отказ с обязательным комментарием, закрытие редактирования, сохранённый результат.
- Проверка: оценка полей, действий и времени; заключение преподавателя (append-only);
  экспериментальный балл; отчёт CSV; выгрузка JSONL проверенных заключений.
- Роли: обучающийся, преподаватель, администратор (JWT, Argon2); паспорт стенда `/readiness`.
- Учебный телефон (имитация входящего вызова), классификатор 1 283 строки v046_24,
  офлайн-карта Москвы (OSM/PMTiles); маркер и маршрут учебные.
- **Новое (29.09):** генерация учебных сценариев в интерфейсе преподавателя — выбор типа,
  сложности и количества → предпросмотр вариантов локальной модели → импорт одобренных
  с авторством проверившего. Тот же путь доступен через CLI.

## ML

Реальная GigaChat3.1 из release Кирилла подключена к оценке комментариев через
loopback evaluator. Сквозной вызов API/БД/модели, конкурентное завершение и отказ
evaluator проверены: [протокол модели](evidence/real-ml-integration.json).
Режимы: `ML_MODE=mock` (по умолчанию, без сети), `local` (модель отвечает,
включая генерацию сценариев) и автоматический fallback при недоступности.
Баллы остаются экспериментальной формулой команды; официальная методика не утверждена.

## Как запустить

Команды: [базовый запуск](DEPLOYMENT.md), [ML запуск](LOCAL_ML_RUN.ru.md),
[инструкция для заказчика](CUSTOMER_GUIDE.ru.md) — три подхода: Docker Compose,
Windows без Docker и GitHub Codespaces.
Windows: UI http://127.0.0.1:5173, API http://127.0.0.1:8000/docs.
Подготовленный стенд работает локально; зависимости и веса готовятся заранее.
