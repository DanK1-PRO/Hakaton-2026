## 2. Унифицированная карточка: требования и перечни полей

### 2.1. Требования к составлению (приложение к № 1931)

URL: https://sudact.ru/law/postanovlenie-pravitelstva-rf-ot-12112021-n-1931/obiazatelnye-trebovaniia-k-organizatsii-i/prilozhenie/

| Факт |
|---|
| Карточка документирует каждый вызов: операторы-112 + диспетчеры ДДС |
| Заполнение **начинается с общей части**; ЭРА-ГЛОНАСС и оператор связи — авто; далее характер/тип, место, заявитель |
| Заполнение **классификаторами**. Общая часть: состояние реагирования; место; улица; дорога; язык общения; объект; тип происшествия |
| Специальные части — по списку привлекаемых ДДС (можно несколько) |
| Классификаторы специальной части: вид происшествия; вид правонарушения; рост; телосложение; тип/цвет ТС; вид вызова; степень родства позвонившего; вид несчастного случая; вид заболевания; поликлиника; вид обращения в ДДС ЖКХ; вид теракта |
| В процессе реагирования ДДС вносят сведения о **начале, ходе, завершении** и основных результатах |
| Комплексное реагирование: в специальной части отражаются переданные распоряжения, действия подчинённых подразделений, изменения обстановки, взаимодействие с другими ДДС |

### 2.2. Приложение N 1 — общая информационная часть (оператор 112)

URL: https://sudact.ru/law/postanovlenie-pravitelstva-rf-ot-12112021-n-1931/obiazatelnye-trebovaniia-k-organizatsii-i/prilozhenie/prilozhenie-n-1/

Группы полей:

1. **Служебное**: Дата, Время (авто), Состояние (классификатор, по умолчанию «начало»).
2. **Абонентское устройство (авто)**: Телефон; ФИО владельца (БД оператора связи); Адрес установки (местный телефонный узел); широта/долгота; точность координат (ЭРА-ГЛОНАСС/оператор связи).
3. **Заявитель**: ФИО; Телефон (по умолчанию = номер устройства); Язык общения (классификатор); Адрес (не обязательно).
4. **Место происшествия**: Место (ОКАТО); Улица; Дом/дробь/корпус/строение/владение; Подъезд; Этаж (подвал — со знаком «−»); Квартира/офис; Код домофона; Дорога; Километр; Метр (точность 100 м); Адресный участок; признак «Рядом»; Объект (ОКПО); Уточнение.
5. **Происшествие**: Тип происшествия (сводный классификатор); Описание; Число пострадавших; Угроза людям (флаг эвакуации); Признак ЧС; Дополнительная информация.
6. **Привлечённые ДДС**: Наименование (классификатор ДДС, выбирает оператор); **Время приказа на выезд**; **Время прибытия**; **Время окончания мероприятий** (заполняет диспетчер ДДС).
7. **Вкладка ЭРА-ГЛОНАСС (ДТП)**: тип вызова (экстренный/тестовый); вид срабатывания; флаг пострадавших/первой помощи; голосовое соединение с ТС; тип ТС; VIN; тип двигателя; направление движения; 2 пары координат; флаг достоверности локации; число пассажиров; краткий/уникальный ссылочные идентификаторы.

**Вывод для симулятора**: набор полей нашей карточки (адресная сетка 14 полей, тип/классификатор, пострадавшие, службы) в целом соответствует Приложению 1; времена приказа/прибытия/окончания — обязанность диспетчера, не оператора.

### 2.3. Приложение N 2 — специальная часть (по службам)

URL: https://sudact.ru/law/postanovlenie-pravitelstva-rf-ot-12112021-n-1931/obiazatelnye-trebovaniia-k-organizatsii-i/prilozhenie/prilozhenie-n-2/

| Служба | Ключевые поля |
|---|---|
| **Пожарная охрана** | характер происшествия; обстоятельства/объект; этажность; объект газифицирован; оценка времени развития пожара; наблюдаемые последствия; подъездные пути; условия работы (ворот/шлагбаумы); необходимость спасработ; оценка эвакуации; собственники/арендаторы (адреса, телефоны) |
| **Полиция** | вид правонарушения; число правонарушителей; число ТС; **по подозреваемому**: пол, возраст «на вид», рост, телосложение, одежда, приметы; **по разыскиваемому**: ФИО, дата рождения, возраст, рост, телосложение, одежда, приметы; **по ТС**: тип, цвет, госномер, регион, «скрылось»; вкладка ЭРА-ГЛОНАСС |

| **Аварийная служба газа** | вид происшествия; **Инструкции** (авто из справочника — действия оператора/заявителя); флаг «Консультация» |
| **ДДС ЖКХ** | вид происшествия (классификатор обращений); коммунальная служба (справочник МО); **Инструкции** (авто по службе); флаг «Консультация» |
| **Антитеррор** | вид теракта; погибшие/пострадавшие/подозреваемые; описание, вооружение, ТС, направление движения, повреждения подозреваемых |

**Вывод**: «Консультация» (газ/ЖКХ/скорая) — официальный триггер авто-перевода состояния в «завершено»; инструкции для ЖКХ/газа подтягиваются из справочника — применимо к тренажёру как подсказка-скрипт.

## 4. Экстренные vs ЖКХ: официальная рамка

| Факт | Источник |
|---|---|

## 10. Чек-лист обучения (на основе подтверждённых источников)

База: № 1931 (алгоритм и нормативы), Приложения 1–2 (поля), методрекомендации ВНИИ ГОЧС (режимы, обязанности), клиентская памятка АРМ-112 (статусы ПРИНЯТО/ОТКАЗ/ЗАВЕРШЕНЫ — из customer materials).

### A. Роли и контур
- [ ] Отличает оператора системы-112 (общая часть, распределение, перенаправление) от диспетчера ДДС (специальная часть, реагирование) от ЕДДС (контроль, снятие с контроля).
- [ ] Знает три режима ЕДДС и что вне-сферы → незамедлительно своей ДДС, ЧС → первоочередно в ЕДДС.

### B. Алгоритм вызова (п. 9)
- [ ] Принятие: запись, карточка, авто-номер/место.
- [ ] Опрос обязательных полей до ~75 с (среднее) до готовности карточки для ДДС.
- [ ] Выбор ДДС по критериям/зоне; при экстренности — извещение | завершение | перенаправление голоса.
- [ ] Двойное подтверждение при перенаправлении: получение + зона ответственности; затем заявителю «начато реагирование».
- [ ] Ожидание подтверждения ДДС ≤ 30 с; при обрыве — обратный вызов ≤ 10 с, ≥ 3 попытки, ожидание ≤ 1 мин.
- [ ] Отметки диспетчера: получение → приказ на выезд → прибытие → окончание → отметка снятия; снятие ЕДДС только от **всех** служб.

### C. Карточка (Приложения 1–2)
- [ ] Заполняет общую часть по группам полей (служебное, абонент, заявитель, место, происшествие, службы).
- [ ] Знает классификаторы общей части (состояние, место, улица, дорога, язык, объект, тип).
- [ ] Для «своей» службы ДДС — специальные поля (пожар/полиция/скорая/газ/ЖКХ/антитеррор).
- [ ] Понимает «Консультацию» как путь завершения без выезда (газ/ЖКХ/скорая).
- [ ] Времена приказа/прибытия/окончания — вносятся диспетчером, не оператором.

### D. Коммуникация с заявителем
- [ ] Уточняющие вопросы: точный адрес (дом/корпус/строение/этаж), этажность, характер, угроза распространения, люди/угроза жизни.
- [ ] Уточнение по телефону заявителя из карточки в ходе реагирования.
- [ ] Консультация ≤ 2 мин; психологическая поддержка ≤ 30 мин; иностранный язык — переводчик/оператор.

### E. Нормативы (зубрёжка)
