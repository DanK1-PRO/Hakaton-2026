# Offline Map Plan

Версия: 2026-09-21. Статус: архитектурное решение для закрытого контура.

## Что сделано сейчас

В `frontend/src/arm/MapPanel.tsx` реализована полностью локальная учебная карта Москвы:

- без Yandex/Google/2GIS/API-ключей;
- без передачи адреса происшествия во внешний сервис;
- со встроенной схемой административных зон Москвы, маршрутной дугой службы и маркером адреса;
- с детерминированным позиционированием адреса по известным московским округам/улицам и safe fallback для остальных адресов.

Это достаточно для программы-минимум: диспетчер видит кнопку `карта`, адрес карточки, район и учебный маршрут, а проект остаётся работоспособным без интернета.

## Почему не внешний API

Система должна запускаться локально и быть пригодной для закрытого контура. Внешние карты требуют сетевого доступа и обычно отправляют адрес/координаты наружу. Поэтому карта в текущей ветке не запрашивает ключ и не делает geocoding/fetch к внешнему провайдеру.

## Следующий технический слой

Если после ML-синхронизации понадобится геометрически точная карта, подключать её так:

1. Взять открытые OSM-данные по Москве/Московскому региону.
2. Подготовить локальный tiles-пакет в формате PMTiles или MBTiles.
3. Положить пакет в исключённый из Git каталог, например `frontend/public/maps/moscow.pmtiles` или `runtime/maps/moscow.pmtiles`.
4. Подключить MapLibre GL JS как renderer, но только к локальному URL/файлу.
5. Оставить текущий `MapPanel` API неизменным: компонент получает адрес/координаты из карточки и выбирает локальный слой.

## Рекомендуемые источники и движки

- OpenStreetMap: открытые данные под ODbL; при использовании нужна атрибуция.
- Geofabrik: готовые OSM `.osm.pbf` выгрузки, можно брать региональные/российские extract-файлы и резать до Москвы.
- PMTiles: один файл с тайлами, удобно хранить и отдавать локальным HTTP-сервером или из `public/`.
- MapLibre GL JS: WebGL renderer для vector tiles в браузере; подходит для будущей плавной карты внутри React.

## Ограничения текущей схемы

Текущий встроенный слой не является кадастровой/навигационной картой и не заменяет точную ГИС. Он нужен для тренажёра и интерфейсной интеграции до появления согласованного локального map pack.
