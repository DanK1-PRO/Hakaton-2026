База: main `1b1230e`, ранее объединённые UI и выбранные runtime-модули ML.
Текущий документ описывает проверенные возможности, а не официальную приёмку всего ТЗ.

## Реальная модель

Источник: [release Кирилла](https://github.com/DanK1-PRO/Hakaton-2026/releases/tag/modelURL).
GigaChat3.1-10B-A1.8B-q4_K_M: семь частей, каждая проверена по SHA-256 release.
Собранный файл: 6 474 702 976 байт;
SHA-256 `68a8732fb5cee04f83ebffd7924e15c534d4442c5a43d2ba9e2041fe310b8deb`.
Веса лежат в игнорируемой `.runtime/models`, в Git не включаются.

Проверенный runtime: llama.cpp b11223 (4da633776), Windows CUDA 12.4,
RTX 4060 8 GB, 16 GB RAM, контекст 4096. В одном контрольном примере:
обработка промпта 6,22 с, генерация 1,49 с, всего инференс 7,71 с.
Это измерение одного примера, не гарантия задержки на любом компьютере.
Холодная загрузка может занимать несколько минут при одновременной сборке/тестах.

Сквозной протокол: [реальная модель](evidence/real-ml-integration.json).
Проверены сохранение ответа, идентичный ответ двум конкурентным finish-запросам,
переход в fallback при остановке evaluator. UI общается только с основным API.

## Остаточные ограничения

- Телефон пока программная эмуляция состояний. ASR/TTS и голосовой диалог с бригадой не поставлены этим релизом.
- Официальная шкала баллов отсутствует. Формула команды и оценка комментариев требуют проверки преподавателем.
- Экспорт заключений создаёт материал для будущего обучения, но не запускает автоматическое дообучение.
- Автоматический корпус классификатора не является утверждённой базой заданий. Импорт в рабочий каталог требует методической проверки.
- Карта Москвы работает локально. Точное геокодирование, реальные базы бригад и маршрутизация по дорогам отсутствуют.
- Число одновременных пользователей и голосовых сессий из полного ТЗ нагрузочно не подтверждено.
- Статусный редактор сохраняет разрешённые памяткой переходы; полный учебный цикл задаётся эталоном задания. Уточнение обязательности всех промежуточных этапов остаётся методическим вопросом.
- Шифрование персональных полей и официальное соответствие ГОСТ не подтверждены. Демонстрация использует синтетические данные.
- Первичная подготовка зависимостей/весов требует скачивания. Работа подготовленного стенда локальная; перенос в закрытый контур требует заранее подготовленных runtime и артефактов.

Старые `LocalAPI` и `hht` не заменяют основной API: основания решения сохранены в
[разборе веток](team/ML_BRANCH_REVIEW.ru.md). Финальный прогон не означает механический merge несовместимых деревьев.
