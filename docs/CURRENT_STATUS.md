# Текущее состояние

Обновлено: 28.09.2026. Рабочая сборка UI/API/PostgreSQL и локального ML.

Реализованы русский АРМ, учебные сценарии, история действий, статусы с комментариями,
результаты, проверка преподавателем, CSV и JSONL проверенных заключений.
Карта Москвы использует локальные OSM/PMTiles; маркер и линия маршрута учебные.

Реальная GigaChat3.1 из release Кирилла подключена к оценке комментариев через
loopback evaluator. Сквозной вызов API/БД/модели, конкурентное завершение и отказ
evaluator проверены: [протокол модели](evidence/real-ml-integration.json).
Баллы остаются экспериментальной формулой команды. Генерация новых заданий
работает через CLI с отдельным импортом после проверки преподавателем.

Команды: [базовый запуск](DEPLOYMENT.md), [ML запуск](LOCAL_ML_RUN.ru.md).
Windows UI: http://127.0.0.1:5173. API: http://127.0.0.1:8000/docs.
Подготовленный стенд работает локально; зависимости и веса готовятся заранее.

33 backend-теста пройдены. Актуальные браузерные/CI результаты фиксируются в
[VERIFICATION](VERIFICATION.md). Ранее объединённый main уже прошёл CI;
результат нового прохода нельзя выводить только из результата старого коммита.

Остаточные ограничения: реальный голос ASR/TTS, автоматическое дообучение,
точное геокодирование, официальный эталон оценивания, нагрузочные требования
всего ТЗ, шифрование персональных полей и подтверждённое соответствие ГОСТ.
Использовать синтетические данные. Полный перечень и исправленные стыки:
[финальный аудит](FINAL_INTEGRATION_AUDIT.ru.md).

[Комплект сдачи](SUBMISSION.ru.md) подготовлен как индекс. Публичность/гостевой доступ,
ссылка внешнего прототипа или скринкаста, финальная презентация и отправка формы
остаются действиями команды. Автоматически заказчику ничего не отправлялось.
