# Финальный чеклист сдачи

Документ предназначен для последней проверки перед передачей ссылки на репозиторий и материалы жюри. Он фиксирует практический порядок действий, а не расширяет состав реализованных функций.

## Что должно быть доступно проверяющему

| Репозиторий | `https://github.com/DanK1-PRO/Hakaton-2026` |
| Быстрый запуск | `README.md`, раздел «Быстрый запуск» |

| Границы готовности | `docs/FINAL_INTEGRATION_AUDIT.ru.md` |
| Локальная ML-модель | `docs/LOCAL_ML_RUN.ru.md` и GitHub release `modelURL` |

## Проверка на чистой машине / виртуальной машине

Основной путь для проверяющего — Docker Compose:

```bash
git clone https://github.com/DanK1-PRO/Hakaton-2026.git
cd Hakaton-2026
python scripts/init_local.py
docker compose up --build -d --wait
```

Открыть:

- UI: `http://localhost:8080`
- API/Swagger: `http://localhost:8000/docs`
- Health: `http://localhost:8000/health`

Нативный Windows-запуск без Docker описан в `docs/DEPLOYMENT.md`. Он создаёт `.venv`, локальный PostgreSQL в `.runtime`, API на `127.0.0.1:8000` и UI на `127.0.0.1:5173`.

Перед публичным доступом пароль задаётся через `DEMO_PASSWORD` до первичного seed. Для локальной проверки допустим пароль по умолчанию.

## Что показать за 3-5 минут

1. Войти как обучающийся.
2. Открыть «Учебные задания» и запустить сценарий.
3. В карточке показать АРМ-подобный интерфейс: адрес, классификацию, службы, карту и связь.
4. Поставить статус «Принята», затем пройти реагирование до «Работы завершены» с комментарием.
5. Завершить занятие и показать результат автоматической проверки.
6. Войти как преподаватель, открыть «Контроль занятий» и добавить заключение.

## Перед отправкой формы

- Проверить, что репозиторий открыт жюри или выдан гостевой доступ.
- Проверить, что ссылки на презентацию, скринкаст и дополнительные материалы доступны «по ссылке».
- Зафиксировать commit SHA сдаваемой версии.
- Зафиксировать версию release модели `modelURL`, если демонстрируется локальная ML-проверка.
- Не изменять сданные ссылки, презентации, документацию и код после стоп-кода.

## Честные границы версии

Система является локальным учебным контуром. Она не выполняет реальные вызовы в 112/ДДС, не является сертифицированной боевой АРМ, не содержит автоматического дообучения модели и не заявляет официальную методику балльной оценки. Эти ограничения отражены в `docs/FINAL_INTEGRATION_AUDIT.ru.md`.
