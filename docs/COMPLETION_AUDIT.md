# Аудит Программы-Минимум

Основание: MASTER_SPEC §§34-35, текущий запрос Даниила и границы этапа из HANDOFF.
Это проверка текущего командного вклада, а не приёмка всей будущей системы заказчика.

## Учебный Цикл, §34

| № | Требование | Реализация и доказательство |
|---|---|---|
| 1 | Вход обучающегося | JWT/Argon2; серверные и браузерные проверки входа |
| 2 | Начало задания | 3 сценария; идемпотентное создание активной сессии |
| 3 | Входящая задача/сообщение/вызов | incoming-событие карточки и учебный телефон ring/answer/hangup |
| 4 | АРМ-подобный интерфейс | UI_SOURCE_MAP; фактические desktop/mobile снимки |
| 5 | Заполнение и передача результата | Форма, классификатор, статус реагирования, завершение |
| 6 | Фиксация времени/действий | Серверные timestamps, аудит, журнал, 30-секундное подтверждение |
| 7 | Сравнение с эталоном | Детерминированный gateway; локальный HTTP-адаптер |
| 8 | Ошибки/критические ошибки/время | EvaluationResult v1.0, русский экран результата |
| 9 | Просмотр и корректировка преподавателем | Отдельное заключение/правильное действие, исходная оценка сохранена |
| 10 | Работа при отказе ML | HTTP-отказ, тайм-аут, неверный DTO/идентификатор; явный fallback |

## Критерии Даниила, §35

| Критерии | Проверяемые файлы / действия |
|---|---|
| FastAPI, запуск, health | app/main.py; реальный GET /health: database=ok |
| Авторизация, JWT, роли | auth.py; auth/ownership/staff boundary tests |
| CRUD происшествий | routers/api.py; create/read/update/delete/filter тест |
| Версионированные модели | models.py; migration 0001; config JSON Schema/OpenAPI |
| Swagger | /docs и /openapi.json, экспорт в config/openapi.json |
| Запуск без ML | ML_MODE=mock; нативная и контейнерная конфигурация |
| React Login/Incident List | App.tsx/pages.tsx; Playwright с реальным API |
| Redux/API client | store.ts, RTK Query; React обращается только к FastAPI |
| Compose api/ui/db | GitHub containers job: build, migrations, seed, health |
| PostgreSQL | PostgreSQL 15; миграции и сохранность после перезапуска |
| Ссылки на источники | SOURCE_OF_TRUTH, FILE_MANIFEST, REQUIREMENTS_TRACEABILITY |
| План капитана | Согласованный стек; ML отделён; макет по памятке/скринам ДДС |

## Дополнительная Поставка

- Приватный GitHub: русское/английское README, демонстрации, CI, правила участия
  и безопасности, скриншоты, инструкции запуска.
- Физические AGENTS.md, docs/ai и 5 проектных skills; валидатор всех skills проходит.
- Рабочая ведомость, архитектура, руководство, методика испытаний и PDF.
- Источники заказчика, пароли и локальная БД исключены из Git.

Итоги конкретных запусков и ограничения находятся в VERIFICATION.md.
Нельзя превращать наличие этого списка в доказательство: его строки опираются
на тесты/скриншоты/CI, а не заменяют их. Реальные модели, SIP, полная нагрузочная
приёмка и утверждение документов остаются за пределами согласованного этапа.
