# Задачи НИКИТЫ — Рабочее место диспетчера и карточка происшествия

Ветка: `ui/nikita-card-flow`

## Зона ответственности

Рабочее место диспетчера, карточка происшествия, состояния вызова, адаптивность и удобство основного training flow.

## Файлы для работы

- `frontend/src/workspace.tsx`
- `frontend/src/components.tsx`
- `frontend/src/styles.css`
- `frontend/tests/flow.spec.ts`
- `docs/ui/UI_BEHAVIOR.md`
- `docs/ui/SCREEN_MAP.md`

## Диапазон задач (первый прогон)

### 1. Улучшить эргономику карточки вызова
- Плотность и читаемость полей
- Группировка полей по логическим блокам
- Индикация состояний вызова: received, accepted, rejected, responding, arrived, working, completed, refused

### 2. Довести мобильную и desktop-адаптацию
- Проверить ширину 390px без горизонтального скролла
- Адаптивная вёрстка карточки и панели диспетчера

### 3. Улучшить отображение истории действий
- Визуализация через Timeline
- Хронологический порядок действий

### 4. Сделать понятнее состояния вызова
- Визуальные индикаторы для каждого состояния
- Подсветка текущего состояния

### 5. Добавить loading/error/empty состояния
- Состояния загрузки данных
- Обработка ошибок API
- Пустые состояния при отсутствии данных

## Ограничения

- Не менять названия API-полей
- Не менять порядок жизненных состояний карточки
- Не отключать проверку версии карточки
- Не делать React-запросы напрямую к ML-сервису

## Проверки перед PR

```powershell
cd frontend
npm run build
npx playwright test
```

## Готовность задачи

- UI работает на desktop и mobile
- Нет горизонтального скролла на 390px
- Русские тексты не обрезаются
- Сохраняется прохождение полного учебного сценария
- Не сломаны роли
- `npm run build` проходит
- Playwright проходит
