# Текущее состояние

Обновлено: 20.09.2026. Версия: 0.1.0.

Программа-минимум Даниила реализована: русский АРМ, API, PostgreSQL, учебные задания,
mock/local ML, результаты и контроль преподавателя. Приложение работает локально
без облачных моделей. Это не заявление о выполнении всего общего ТЗ команды.

Проверено локально: 15 серверных тестов, 8 браузерных тестов (1440 и 390 px),
TypeScript/build, аудит зависимостей, сохранность результатов после перезапуска,
отдельный ML-процесс и его отказ. Docker Compose и повторный полный прогон на Linux
прошли в GitHub Actions; ссылки и результаты находятся в [протоколе](VERIFICATION.md).

Windows: http://127.0.0.1:5173, API: http://127.0.0.1:8000/docs.
Compose: http://localhost:8080.
Команды запуска и остановки: [развёртывание](DEPLOYMENT.md).

## Не Подменять Готовностью

- Реальные ML-веса, генератор/ASR/SIP ещё не подключены.
- Официальная балльная методика и демонстрационные эталоны не утверждены заказчиком.
- 100 пользователей, 100 записей/с, 20 голосовых сессий и вся программа
  нагрузочных испытаний общего ТЗ пока не подтверждены.
- Сетевой сбой сохраняет открытый редактор; долговременная offline-очередь не реализована.
- pgcrypto подключено, но шифрование персональных полей не реализовано.
  Использовать только синтетические учебные данные.
- PDF с билетами состоит из сканов; автоматическое распознавание всех билетов не выполнено.
  Три проверяемых занятия основаны на примерах памятки ДДС, а не выданы за полную базу билетов.

Следующий этап начинается после согласования командных DTO и реальных ML-пакетов,
а не с повторного создания каркаса. См. [границы интеграции](ML_INTEGRATION.md).
